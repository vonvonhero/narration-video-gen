# 検証結果

**日本語** | [English](evidence_en.md)

`profiles/`の各構成には、どこまで検証したかを示すラベルが付いています。
構成ごとの一覧は[ハードウェア対応表](hardware-matrix.md)を参照してください。

## ラベルの意味

| 項目 | 値 | 意味 |
|---|---|---|
| `duration_class` | `full` | ナレーション全体を生成した |
| | `short` | 約5.6秒の短尺だけを生成した |
| | `gate` | 途中で停止した容量確認。完成動画はない |
| `gpu_evidence` | `physical` | そのVRAM容量のGPUで実行した |
| | `capacity-simulated` | 大きいGPUの一部を確保し、小さいVRAMを再現して実行した |
| `visual_review` | `passed` | 人が動画を見て合格とした |
| | `pending` | 人が見ていない |
| | `failed` | 人が見て不合格とした |

`short`は、メモリに収まることだけを示します。長い動画で蓄積する劣化は確認できません。
`capacity-simulated`の結果は、実際の8 GiB・12 GiBのGPUより使えるメモリが多い条件です。
`status`は`recommended`、`acceptable`、`experimental`、`not-recommended`の4段階です。
`full`・`physical`・`passed`でない構成では、`plan`がその制限を表示します。

## 設定の方針

- **tiled VAEは使いません。** 長い動画で格子状のノイズが蓄積するためです。
  `linux-wan21-720p-vram24-tiled`は参考として残している非推奨の構成です。
- **block swapは速度だけに影響します。** `blocks_to_swap=40`でも、スワップなしと同等の
  画質でした。
- **不要なblock swapは使いません。** VRAMに余裕があるGPUでスワップすると遅くなり、
  GPUがハングする場合もあります。VRAM容量ごとに別の構成を用意しています。

## 実測結果

約30秒のナレーションを、生成・顔補正・フレーム補間・60 fps化まで
通した結果です。所要時間はGPUの冷却や電力制限によって大きく変わります。

| Wan 2.1 | 720p | RTX A4000 16 GiB | 28 | 約147分 | 合格 |
| Wan 2.1 | 480p | RTX 3090 24 GiB | 0 | 約26分 | 合格 |
| Wan 2.1 | 720p | RTX 3090 24 GiB | 8 | 約81分 | 合格 |
| Wan 2.2 | 480p | RTX A4000 16 GiB | 20 | 約32分 | 合格 |
| Wan 2.2 | 720p | RTX A4000 16 GiB | 32 | 約95分 | 合格 |
| Wan 2.2 | 480p | RTX 3090 24 GiB | 0 | 約19分 | 合格 |
| Wan 2.2 | 720p | RTX 3090 24 GiB | 11 | 約72分 | 合格 |

### 12 GiB以下

12 GiB以下の構成は、Q4_K_Sのモデルを使います。Wan 2.2の480pは、8 GiB相当・12 GiB相当とも
フル尺を完走し、目視で合格しています（容量シミュレーション、途中で再開を含む）。
それ以外の12 GiB以下の構成は、短尺のみの確認、短尺でのメモリ不足、または未検証の候補です。詳しくは
[低VRAM向けモデル選択](low-vram-model-policy.md)を参照してください。

## 注意事項

- RAMとswapの要件は、検証に使ったマシンの値です。最小値ではありません。
- 同じ設定でも、GPUの種類が違うと出力はビット単位では一致しません。
- 所要時間の見積もりには、冷却が十分な環境での実測値を使います。
