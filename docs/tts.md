# ナレーションを作る

**日本語** | [English](tts_en.md)

Irodori-TTS v4.1 Smallで、台本から動画用の音声を作ります。

## ブラウザで作る

```bash
./bin/narration-video-gen tts
```

音声作成画面が開きます。

1. 葵・さくら、または自分で作ったキャラクターを選び、台本を入力します。
2. **音声を作る**を押します。初回はモデル一式（約3.7GB）をダウンロードします。実行環境の作成手順、ダウンロード量と速度、残り時間の目安が画面に表示されます。途中で再読み込みしても進捗表示に戻ります。
3. 完成音声と各パートを聴き、確認欄にチェックを入れます。
4. **この音声を動画の入力にする**を押します。次に`./bin/narration-video-gen run`で、作成した入力セットを選びます。

改行でパートを分け、長い行は句読点でも分割します。空行を入れると文の間が長くなります。
入力欄の下で実際の区切りを確認できます。CPUでの生成には数分かかることがあります。

### 音声を調整する

- **文の間を変える:** 「次の文まで」を変更し、**間の変更を反映する**を押します。
- **言い方・長さを変える:** 各パートの**このパートだけ作り直す**を開きます。seedを変えると言い方が変わり、長さは1.0を基準に調整できます。**最初のseedに戻す**で初期値を使えます。
- **読み方を直す:** 台本を編集して**音声を作る**を押します。難しい漢字や固有名詞は、ひらがなにすると読みやすくなります。
- **話し方・最後の余韻を変える:** **話し方などの詳細設定**で変更できます。余韻の初期値は1.5秒です。

音声認識の照合結果は、各パートに表示されます。「要確認」のパートは読み飛ばしや余計な発話がないか聴いてください。表記の違いで印が付くこともあります。

**前に作ったもの**から音声を開き直せます。生成中にタブを閉じた場合も、音声作成サービスが動いていれば処理は続きます。

## キャラクターを作る

**＋ キャラクターを作る**から、名前・声・話し方・画像を設定します。

- **声を文章で作る:** 「落ち着いた女性の声。自然なテンポで明瞭に話す。」のように書きます。**別の声にする**で声の個体差を変えて試せます。
- **音声を指定する:** mp3・m4a・wavなどの話し声を選びます。自分の声、または本人から使用の許可を得た声を使ってください。
- **既存のキャラクターを引き継ぐ:** 声・画像・seedを引き継ぎ、話し方を変えられます。画像は省略すると元のキャラクターのものを使います。

参照音声は2秒以上必要で、10秒以上が目安です。120秒を超える場合は先頭120秒を使います。
声がこもると表示された場合、文章から作った声なら**別の声にする**、録音なら別の音声ファイルを試してください。

画像は動画の最初のフレームに使います。**16:9・中央でトリミング**されるので、プレビューで顔が切れていないか確認します。

作成後に試し聞きし、**このキャラクターを使う**で台本の入力へ進みます。
気に入らなければ**別の声にする**で試し直すか、**やめる（削除）**で取り消せます。

### 作成後の変更

キャラクターを選ぶと、**声を作り直す**・**画像を差し替える**・**削除する**が表示されます。
声の作り直しは、文章から作った声だけで使えます。

そのキャラクターで作った音声が残っている場合、声の作り直しと削除はできません。別の声を使うには、新しいキャラクターを作ります。同梱の葵とさくらは変更・削除できません。

自作キャラクターは`voices/`、生成した音声は`outputs/tts/<job-id>/`に保存します。

## CLIで作る

```bash
# 台本の区切りを確認
./bin/narration-video-gen tts plan --script inputs/my-video/script.txt

# 初回のモデル準備と音声エンジンの起動
./bin/narration-video-gen tts prepare
./bin/narration-video-gen tts backend start

# 音声を生成
./bin/narration-video-gen tts generate \
  --script inputs/my-video/script.txt \
  --character aoi \
  --output inputs/my-video/audio.wav
```

生成後に表示されるURLで音声を聴きます。音声認識での照合は既定で有効です。省略する場合は`--skip-asr`を付けます。

確認した音声を動画の入力セットにするには、表示されたジョブIDを指定します。

```bash
./bin/narration-video-gen tts adopt <job-id> --name my-video --confirm-listened
```

## 起動・停止と別端末からの利用

```bash
./bin/narration-video-gen tts web status
./bin/narration-video-gen tts web stop
```

同じLANの端末から使う場合:

```bash
./bin/narration-video-gen tts web reset-password
./bin/narration-video-gen tts web start --lan --no-open
```

パスワードはLAN公開時に必須で10文字以上です。ユーザー名は`tts`固定で、
ログイン画面ではパスワードだけを入力します。忘れた場合も同じ
`reset-password`コマンドをSSHまたはローカル端末で実行します。パスワードは平文保存しません。
localhost限定で起動済みの場合は、待受設定を変更して再起動します。
通信はHTTPのため、LAN公開は信頼できるローカルネットワーク内でだけ使ってください。

動画生成を始めると、GPUメモリを空けるため音声エンジンが停止します。Web UIは開いたまま使え、次の音声生成時にエンジンが再起動します。

## モデルと音声形式

初回はTTSモデル・codec・Whisper Base・SilentCipherのモデルを取得します。モデル一式はMITライセンスです。同梱キャラクターの参照音声は合成音声です。

音声は48kHz・mono・16-bit PCM WAVで保存します。入力セットには音声・キャラクター画像・台本が入ります。
